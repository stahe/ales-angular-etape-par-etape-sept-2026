    8. Comunicación con el servidor

    Los ejemplos de este capítulo consultan el servidor JSON [RdvMedecins]: debe estar en ejecución ([npm run start:dev] en la carpeta [rdvmedecins-nestjs-json]) en el puerto 8080, al mismo tiempo que el servidor de desarrollo de [Angular] en el puerto 4200.

    8.1. Ejemplo 22: una primera solicitud HTTP

    8.1.1. El proxy del servidor de desarrollo

    La página del ejemplo proviene de http://localhost:4200 (el servidor de desarrollo de [Angular], iniciado por [ng serve]); la API está en http://localhost:8080. Para un navegador, son dos orígenes distintos (el puerto forma parte del origen). Sin embargo, por razones de seguridad, un navegador no permite que una página lea las respuestas de otro origen a menos que el servidor lo autorice explícitamente (el mecanismo conocido como CORS). Y una solicitud a otro origen no lleva cookies (y por lo tanto tampoco el token), a menos que el código lo pida ([withCredentials: true]) Y el servidor lo acepte, de nuevo mediante CORS.

    En lugar de abrir el servidor a otros orígenes, hacemos pasar las solicitudes a la API por el servidor de desarrollo de [Angular]. Este es el proxy declarado en el archivo del espacio de trabajo [proxy.conf.json]:

// 22-httpclient/src/app/app.ts - una primera petición HTTP al servidor
// -------------------------------------------------------------------------
// El servidor JSON de RdvMedecins debe estar en ejecución (puerto 8080). Le pedimos
// un captcha: GET /api/captcha -> { "id": "...", "svg": "<svg ...>" }.
//
//   - HttpClient: el cliente HTTP de Angular (proporcionado por defecto a toda la
//     aplicación). http.get<T>(url) devuelve un OBSERVABLE (ver ejemplo
//     19): la petición solo se envía cuando nos SUSCRIBIMOS a él (subscribe);
//     la respuesta JSON llega ya convertida en un objeto, del tipo anunciado T;
//   - la dirección es RELATIVA (/api/captcha): la petición va al
//     servidor de la página, el de Angular (puerto 4200), que la reenvía al
//     servidor JSON (puerto 8080) gracias a su proxy (ver proxy.conf.json);
//   - tres estados que mostrar: cargando, éxito, error.
// =========================================================================

import { Component, computed, inject, signal } from '@angular/core';
import { HttpClient, HttpErrorResponse } from '@angular/common/http';
import { DomSanitizer, SafeHtml } from '@angular/platform-browser';

// lo que devuelve GET /api/captcha
interface Captcha {
  id: string;
  svg: string;
}

@Component({
  selector: 'app-root',
  templateUrl: './app.html',
  styles: `
    .captcha {
      display: inline-block;
      border: 1px solid #dee2e6;
      border-radius: 0.375rem;
    }
  `,
})
export class App {
  private readonly http = inject(HttpClient);
  private readonly sanitizer = inject(DomSanitizer);

  protected readonly captcha = signal<Captcha | null>(null);
  protected readonly loading = signal(false);
  protected readonly error = signal<string | null>(null);
  protected readonly requestCount = signal(0);

  // [innerHTML] inserta una cadena como HTML. Por seguridad, Angular
  // LIMPIA este HTML ("sanitization"): elimina los scripts... y las
  // etiquetas <svg>. bypassSecurityTrustHtml le dice a Angular: "este HTML es
  // seguro, no lo limpies". Debe usarse ÚNICAMENTE con contenido seguro: este SVG
  // lo construye NUESTRO servidor. Con datos del usuario, sería
  // abrir la puerta a la inyección de scripts ({{ }}, en cambio, escapa todo).
  protected readonly svg = computed<SafeHtml | null>(() => {
    const c = this.captcha();
    return c ? this.sanitizer.bypassSecurityTrustHtml(c.svg) : null;
  });

  constructor() {
    this.load(); // al iniciar, cargamos un captcha
  }

  protected load(): void {
    this.loading.set(true);
    this.error.set(null);
    this.http.get<Captcha>('/api/captcha').subscribe({
      // next: la respuesta (código 2xx), ya convertida desde JSON
      next: (captcha) => {
        this.captcha.set(captcha);
        this.requestCount.update((n) => n + 1);
        this.loading.set(false);
      },
      // error: una respuesta 4xx / 5xx, o ninguna respuesta (status 0)
      error: (e: HttpErrorResponse) => {
        this.error.set(`the server answered ${e.status} ${e.statusText}`);
        this.captcha.set(null);
        this.loading.set(false);
      },
    });
  }
}

    • línea 39: se inyecta el cliente HTTP;
    • líneas 42–45: los tres estados de una solicitud: en curso, exitosa (el CAPTCHA) y con error;
    • línea 65: [http.get<Captcha>(url)] prepara una solicitud GET. Devuelve un observable (ejemplo 19): la solicitud se envía solo cuando se suscribe a él ([subscribe]). La dirección es relativa: la solicitud se envía al servidor de la página, que la reenvía al servidor JSON;
    • líneas 67–71: [next] recibe la respuesta, que ya se ha convertido desde JSON. [<Captcha>] informa a [TypeScript] del formato del objeto: el compilador no puede verificar lo que enviará el servidor;
    • Líneas 73–77: [error] recibe un [HttpErrorResponse] ante cualquier respuesta 4xx o 5xx, así como cuando no se recibe ninguna respuesta (servidor caído, red desconectada: [status] vale entonces 0). Si el servidor JSON está caído, el proxy responde con un error 5xx;
    • línea 59: al iniciar, se carga un CAPTCHA;
    • líneas 53–56: la imagen SVG del CAPTCHA es una cadena de caracteres, que debe insertarse como HTML ([[innerHTML]] en la plantilla). Por razones de seguridad, [Angular] depura cualquier HTML insertado de esta manera: elimina los scripts... y las etiquetas [<svg>]. [bypassSecurityTrustHtml] indica que este HTML es seguro. Lo usamos SOLO para contenido seguro: este SVG lo genera NUESTRO servidor. Con datos introducidos por el usuario, esto permitiría inyectar scripts en la página; las dobles llaves [{{ }}], en cambio, escapan todo.

// 23-login/src/app/app.ts - iniciar sesión en el servidor RdvMedecins
// -------------------------------------------------------------------------
//   1. al iniciar: GET /api/auth/me - ¿ya hay una sesión iniciada?
//      (tras un F5, el cliente lo ha olvidado todo; el servidor lee la cookie);
//   2. login: POST /api/auth/login, cuerpo JSON { login, password,
//      captchaId, captcha }. Si tiene éxito, el servidor establece la cookie
//      httpOnly del token JWT: nuestro código NUNCA la ve (pruebe
//      document.cookie en la consola: no está);
//   3. petición protegida: GET /api/doctors. El navegador le adjunta la cookie
//      por sí mismo (mismo origen);
//   4. logout: POST /api/auth/logout - el servidor elimina la cookie.
//
// firstValueFrom(observable): una PROMESA del primer valor del flujo.
// Las cadenas de peticiones pueden escribirse entonces con async / await,
// más legible que una cascada de subscribe. Una respuesta de error rechaza
// la promesa con una HttpErrorResponse: un simple try / catch.
//
// Una cookie pertenece a una máquina (localhost) y a un path (/api): por
// lo tanto es común a TODOS los ejemplos. Una vez iniciada la sesión aquí, los ejemplos
// 24 y 25 también la tienen iniciada.
// =========================================================================

import { Component, computed, inject, signal } from '@angular/core';
import { HttpClient, HttpErrorResponse } from '@angular/common/http';
import { DomSanitizer } from '@angular/platform-browser';
import { FormsModule } from '@angular/forms';
import { firstValueFrom } from 'rxjs';

interface User {
  login: string;
  name: string;
  role: 'ADMIN' | 'DOCTOR' | 'USER';
}
interface Doctor {
  id: number;
  title: string;
  firstName: string;
  lastName: string;
}
interface Captcha {
  id: string;
  svg: string;
}
// la forma de TODOS los errores de la API
interface ApiError {
  statusCode: number;
  key: string;
  params?: Record<string, string>;
}

// los pocos mensajes que necesita este ejemplo (el ejemplo 25 usará ngx-translate)
const MESSAGES: Record<string, string> = {
  'LOGIN.ERROR': 'Incorrect login or password.',
  'ERRORS.WRONG_CAPTCHA': 'The characters you typed do not match the image.',
  'ERRORS.TOO_MANY_ATTEMPTS': 'Too many failed attempts. Try again later.',
};

@Component({
  selector: 'app-root',
  imports: [FormsModule],
  templateUrl: './app.html',
})
export class App {
  private readonly http = inject(HttpClient);
  private readonly sanitizer = inject(DomSanitizer);

  protected readonly user = signal<User | null>(null);
  protected readonly doctors = signal<Doctor[]>([]);
  protected readonly captcha = signal<Captcha | null>(null);
  protected readonly svg = computed(() => this.sanitizer.bypassSecurityTrustHtml(this.captcha()?.svg ?? ''));
  protected readonly login = signal('admin');
  protected readonly password = signal('');
  protected readonly captchaAnswer = signal('');
  protected readonly error = signal<string | null>(null);
  protected readonly ready = signal(false); // ¿terminó la verificación inicial?

  constructor() {
    this.checkSession().catch(() => {
      this.error.set('Is the RdvMedecins JSON server running (port 8080)?');
      this.ready.set(true);
    });
  }

  protected async loadCaptcha(): Promise<void> {
    this.captcha.set(await firstValueFrom(this.http.get<Captcha>('/api/captcha')));
    this.captchaAnswer.set('');
  }

  // 1. ¿quién ha iniciado sesión? 200 -> el usuario; 401 -> nadie
  private async checkSession(): Promise<void> {
    try {
      this.user.set(await firstValueFrom(this.http.get<User>('/api/auth/me')));
      await this.loadDoctors();
    } catch (e) {
      if (!(e instanceof HttpErrorResponse) || e.status !== 401) {
        throw e; // no es un 401: el servidor no responde
      }
      await this.loadCaptcha();
    }
    this.ready.set(true);
  }

  // 2. el login; post(url, body): el cuerpo se envía como JSON
  protected async logIn(): Promise<void> {
    this.error.set(null);
    try {
      const u = await firstValueFrom(
        this.http.post<User>('/api/auth/login', {
          login: this.login(),
          password: this.password(),
          captchaId: this.captcha()?.id,
          captcha: this.captchaAnswer(),
        }),
      );
      this.user.set(u);
      this.password.set('');
      await this.loadDoctors();
    } catch (e) {
      // e.error: el cuerpo JSON de la respuesta de error
      const apiError = (e as HttpErrorResponse).error as ApiError | null;
      const key = apiError?.key ?? 'ERRORS.SERVER_UNREACHABLE';
      this.error.set(`${(e as HttpErrorResponse).status} - ${MESSAGES[key] ?? key}`);
      await this.loadCaptcha(); // cada imagen se usa una sola vez
    }
  }

  // 3. una petición protegida
  private async loadDoctors(): Promise<void> {
    this.doctors.set(await firstValueFrom(this.http.get<Doctor[]>('/api/doctors')));
  }

  // 4. el logout
  protected async logOut(): Promise<void> {
    await firstValueFrom(this.http.post('/api/auth/logout', {}));
    this.user.set(null);
    this.doctors.set([]);
    await this.loadCaptcha();
  }
}
    • líneas 30–50: los formatos de los datos intercambiados con el servidor, incluidos los de todos los errores de la API (líneas 46–50);
    • líneas 53–57: los pocos mensajes que necesita este ejemplo, en inglés; el ejemplo 25 usará [ngx-translate];
    • línea 28: [firstValueFrom(observable)] devuelve una promesa con el primer valor del flujo. Una solicitud HTTP produce un único valor, la respuesta: así podemos escribir cadenas de solicitudes con [async] / [await], que son más legibles que una cascada de [subscribe]. Una respuesta de error rechaza la promesa: un simple [try / catch] la captura;
    • líneas 91–102: al iniciar, [GET /api/auth/me]: ¿ya hemos iniciado sesión? Después de recargar la página (F5), la aplicación [Angular] lo ha olvidado todo; el servidor, en cambio, lee la cookie. 200: el usuario; 401: nadie; en ese caso, se muestran el formulario de inicio de sesión y su CAPTCHA (línea 99);
    • línea 96: cualquier otro error significa que el servidor no responde; se informa al desarrollador (líneas 79–82);
    • líneas 105–126: el inicio de sesión:
      • línea 109: [http.post(url, body)]: el objeto [body] se envía como JSON, con el encabezado [Content-Type: application/json];
      • línea 116: si tiene éxito, el servidor ha establecido la cookie del token. Nuestro código NUNCA la ve: escriba [document.cookie] en la consola del navegador; no aparece ([HttpOnly]);

// common/api-error.ts - UNA clase para todos los errores de la API
// -------------------------------------------------------------------------
// Todas las respuestas de error del servidor RdvMedecins tienen la misma forma:
//   { "statusCode": 409, "key": "ERRORS.LOGIN_TAKEN", "params": {...}, "fields": {...} }
// HttpClient las reporta con una HttpErrorResponse, cuya propiedad error
// contiene este cuerpo JSON... u otra cosa: null (sin respuesta), texto
// (una página de error del proxy cuando el servidor JSON está detenido).
// Convertimos todo esto en UNA clase, ApiError, que lleva la clave de
// traducción enviada por el servidor (y, si los hay, sus parámetros y
// el error de cada campo).
// =========================================================================

import { HttpErrorResponse } from '@angular/common/http';

export class ApiError extends Error {
  constructor(
    public readonly statusCode: number, // 0: el servidor no respondió
    public readonly key: string, // p. ej.: 'ERRORS.LOGIN_TAKEN'
    public readonly params: Record<string, string> = {},
    public readonly fields: Record<string, string> = {},
  ) {
    super(key);
    this.name = 'ApiError';
  }
}

// cualquier error -> un ApiError
export function toApiError(e: unknown): ApiError {
  if (e instanceof ApiError) {
    return e;
  }
  if (!(e instanceof HttpErrorResponse)) {
    return new ApiError(0, 'ERRORS.SERVER_ERROR');
  }
  // el cuerpo JSON del error, si existe y tiene la forma correcta
  const body = (typeof e.error === 'object' && e.error !== null ? e.error : {}) as {
    key?: string;
    params?: Record<string, string>;
    fields?: Record<string, string>;
  };
  // sin key: no fue nuestro servidor el que respondió (proxy, red)
  const key = body.key ?? (e.status === 0 || e.status >= 500 ? 'ERRORS.SERVER_UNREACHABLE' : 'ERRORS.SERVER_ERROR');
  return new ApiError(e.status, key, body.params, body.fields);
}

      • línea 37: el cuerpo de la respuesta se usa solo si es un objeto. Cuando el servidor JSON está caído, el proxy responde con texto;

function tomorrow(): string {

  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;

// 25-server-errors/src/app/app.ts - mostrar los errores del SERVIDOR
// -------------------------------------------------------------------------
// La gestión de los clientes (cuenta admin). Este formulario
// NO hace DELIBERADAMENTE ninguna validación en el navegador: su schema está vacío.
// Todo se envía al servidor, que responde, en caso de rechazo, con un error
// JSON (convertido en un ApiError por el interceptor):
//
//   400 { key: 'ERRORS.INVALID_FORM', fields: { lastName: 'ERRORS.LASTNAME_REQUIRED' } }
//   409 { key: 'ERRORS.PATIENT_ALREADY_EXISTS', fields: { firstName: ..., lastName: ... } }
//   409 { key: 'ERRORS.CONCURRENT_UPDATE' }         (bloqueo optimista)
//
// submit(form, action): la action envía el modelo al servidor. Si
// devuelve ERRORS (un arreglo), los formularios con signals los adjuntan
// a los campos designados (fieldTree): aparecen en f.lastName().errors(),
// como los errores de un validador. Su mensaje es aquí la CLAVE enviada por
// el servidor, que la plantilla traduce (ngx-translate). Pruebe: un apellido
// vacío, un título "Dr", un homónimo (Alice DURAND), un login ya usado
// (martin), el mismo registro modificado en dos pestañas...
// =========================================================================

import { Component, computed, inject, signal } from '@angular/core';
import { FormField, form, submit, ValidationError } from '@angular/forms/signals';
import { TranslatePipe, TranslateService } from '@ngx-translate/core';
import { ApiService } from '../../../common/api.service';
import { LoginBar } from '../../../common/login-bar';
import { ApiError } from '../../../common/api-error';
import { Person, User } from '../../../common/types';
// el diálogo de confirmación del ejemplo 16, reutilizado tal cual
import { ConfirmationService } from '../../../16-confirmation/src/app/confirmation/confirmation.service';
import { ConfirmDialog } from '../../../16-confirmation/src/app/confirmation/confirm-dialog';

interface ClientInput {
  title: string;
  firstName: string;
  lastName: string;
  login: string;
  password: string;
  version: number;
}

const EMPTY: ClientInput = { title: 'Mr', firstName: '', lastName: '', login: '', password: '', version: 0 };

@Component({
  selector: 'app-root',
  imports: [FormField, TranslatePipe, LoginBar, ConfirmDialog],
  templateUrl: './app.html',
})
export class App {
  private readonly api = inject(ApiService);
  private readonly confirmation = inject(ConfirmationService);
  protected readonly translate = inject(TranslateService);

  protected readonly user = signal<User | null>(null);
  protected readonly clients = signal<Person[]>([]);
  protected readonly isAdmin = computed(() => this.user()?.role === 'ADMIN');

  // el formulario: editedId === null -> creación, de lo contrario actualización
  protected readonly editedId = signal<number | null>(null);
  protected readonly model = signal<ClientInput>({ ...EMPTY });
  protected readonly f = form(this.model); // sin validador: el servidor valida
  // el mensaje general del último error, y el de un éxito
  protected readonly pageError = signal<ApiError | null>(null);
  protected readonly success = signal<{ key: string; params: Record<string, string> } | null>(null);

  protected async onUserChange(u: User | null): Promise<void> {
    this.user.set(u);
    this.clients.set([]);
    if (u?.role === 'ADMIN') {
      await this.reload();
    }
  }

  private async reload(): Promise<void> {
    this.clients.set(await this.api.get<Person[]>('/clients'));
  }

  protected newForm(): void {
    this.editedId.set(null);
    this.model.set({ ...EMPTY });
    this.f().reset(); // el estado de los campos (y sus errores) parte de cero
    this.clearMessages();
  }

  protected edit(c: Person): void {
    this.editedId.set(c.id);
    // la VERSIÓN leída con el registro vuelve con la actualización: si alguien
    // ha modificado el registro mientras tanto, el servidor responderá 409 CONCURRENT_UPDATE
    this.model.set({ title: c.title, firstName: c.firstName, lastName: c.lastName, login: c.login ?? '', password: '', version: c.version });
    this.f().reset();
    this.clearMessages();
  }

  private clearMessages(): void {
    this.pageError.set(null);
    this.success.set(null);
  }

  // el error de CADA campo, devuelto por el servidor -> un error del formulario
  private fieldErrors(e: ApiError): ValidationError.WithOptionalFieldTree[] {
    const fields = Object.keys(this.model()) as (keyof ClientInput)[];
    return Object.entries(e.fields)
      .filter(([field]) => fields.includes(field as keyof ClientInput))
      .map(([field, key]) => ({ kind: 'server', message: key, fieldTree: this.f[field as keyof ClientInput] }));
  }

  protected async save(event: SubmitEvent): Promise<void> {
    event.preventDefault();
    this.clearMessages();
    const id = this.editedId();
    await submit(this.f, async () => {
      try {
        const body = this.model();
        const client =
          id === null
            ? await this.api.post<Person>('/clients', body)
            : await this.api.put<Person>(`/clients/${id}`, body);
        this.newForm(); // formulario limpiado, mensajes limpiados...
        // ... excepto este
        this.success.set({
          key: id === null ? 'FORM.ADDED' : 'FORM.UPDATED',
          params: { name: `${client.firstName} ${client.lastName}`, login: client.login ?? '' },
        });
        await this.reload();
        return null;
      } catch (e) {
        if (!(e instanceof ApiError)) {
          throw e;
        }
        this.pageError.set(e); // el mensaje general
        return this.fieldErrors(e); // el error de cada campo
      }
    });
  }

  protected async remove(c: Person): Promise<void> {
    const name = `${c.firstName} ${c.lastName}`;
    if (!(await this.confirmation.confirm(this.translate.instant('FORM.DELETE_CONFIRM', { name })))) {
      return;
    }
    this.clearMessages();
    try {
      await this.api.delete(`/clients/${c.id}`);
      this.success.set({ key: 'FORM.DELETED', params: { name } });
    } catch (e) {
      this.pageError.set(e instanceof ApiError ? e : null);
    }
    await this.reload();
  }
}
